Zoteroの業績を、たどれる形に

Zoteroに集約した業績を、年表・研究トピックの変遷・共著者ネットワークとして可視化します。 ブラウザ内で動く埋め込みモデルによる意味検索と、 IEEE / ACM / 情報処理学会 / 電子情報通信学会の引用形式での書き出しに対応しています。

サーバーは使いません。データはあなたのブラウザの中だけで処理されます。

数値のIDです。zotero.org/settings/keys の 「Your user ID for use in API calls is …」に表示されます。 グループライブラリは groups/1234567 の形式で入力できます。
読み取り専用のキーで十分です。入力した内容はこのブラウザから外に出ません（保存もされません）。
表示の設定（任意）
見出しに表示し、共著者の集計から除外します。
和名と欧文表記は文字種が違うため自動では同一人物と判定できません。 1行に1組、和名 = 欧文表記 の形で書くとまとめて集計します。 （欧文の「姓 名／名 姓」の入れ替わりは自動で統合します）
各文献から Zotero を開くリンクに使います。空欄ならリンクを表示しません。
うまく表示されない場合
・コレクション（フォルダ）で分類されていない文献は「未分類」にまとめられます
・発行年が入っていない文献は集計対象外です
・意味検索は初回のみ約120MBのモデルを読み込みます（以降はブラウザに保存されます）
